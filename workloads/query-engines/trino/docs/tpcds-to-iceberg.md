# Materialize TPCDS into Iceberg on ADLS Gen2

TPCDS rows are generated by Trino at query time. Use CTAS to persist the generated rows into Iceberg tables stored in ADLS Gen2.

## Validate the source generator

```sql
SHOW SCHEMAS FROM tpcds;
SELECT count(*) FROM tpcds.sf1.customer;
```

## Create the Iceberg schema

```sql
CREATE SCHEMA iceberg.tpcds_sf1
WITH (
  location = 'abfss://lakehouse@<storage-account>.dfs.core.windows.net/iceberg/warehouse/tpcds_sf1'
);
```

## Materialize starter tables

```sql
CREATE TABLE iceberg.tpcds_sf1.customer
AS SELECT * FROM tpcds.sf1.customer;

CREATE TABLE iceberg.tpcds_sf1.store_sales
AS SELECT * FROM tpcds.sf1.store_sales;

CREATE TABLE iceberg.tpcds_sf1.date_dim
AS SELECT * FROM tpcds.sf1.date_dim;

CREATE TABLE iceberg.tpcds_sf1.item
AS SELECT * FROM tpcds.sf1.item;
```

## Validate persisted data

```sql
SELECT count(*) FROM iceberg.tpcds_sf1.customer;
SELECT count(*) FROM iceberg.tpcds_sf1.store_sales;

SELECT i.i_category, count(*) AS rows
FROM iceberg.tpcds_sf1.store_sales ss
JOIN iceberg.tpcds_sf1.item i
  ON ss.ss_item_sk = i.i_item_sk
GROUP BY i.i_category
ORDER BY rows DESC;
```

Use ADLS Gen2 listing with `--auth-mode login` to confirm files exist without using storage keys:

```bash
az storage fs file list \
  --account-name <storage-account> \
  --file-system lakehouse \
  --path iceberg/warehouse/tpcds_sf1 \
  --auth-mode login \
  -o table
```
